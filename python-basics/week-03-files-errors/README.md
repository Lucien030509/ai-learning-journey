# Week 3: Files and Errors

Completed practice:

- `csv_missing_values.py`: reads `students.csv`, identifies missing scores, and counts them.
- `safe_file_reader.py`: reads a nearby text file safely and handles a missing file without crashing.
- `log_helper.py`: appends learning notes to a text log.

Key ideas: file paths, `Path(__file__)`, `with open(...)`, reading and
writing text files, `try / except`, and reading error messages.

The generated `learning_log.txt` file is deliberately ignored by Git because
it changes whenever the logging program is run.

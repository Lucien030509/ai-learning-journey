# Week 8: Visualisation

This exercise creates a bar chart of average scores for three courses.

## Files

- `first_charts.py`: creates and saves the chart
- `course_scores.png`: generated chart image

## Concepts practised

- `plt.bar()` for a bar chart
- chart title and axis labels
- `plt.bar_label()` for exact values on bars
- `plt.ylim(0, 100)` for an honest score scale
- `plt.savefig()` for a reusable PNG output

## Evidence-based observation

COMP9120 has the highest average score (92), which is 14 points higher than COMP5310 (78).
